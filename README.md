# Gee AI

A collection of small AI and API experiments written in Python.

## Projects

- `smart.py` launches the animal-comparison apps.
- `bird_chicken_app2.py` compares chicken and bird image scores with MobileNetV2.
- `dogcat_app.py` compares dog and cat image scores with MobileNetV2.
- `yt.py` searches YouTube using the YouTube Data API. Set the `YOUTUBE_API_KEY` environment variable before running it.
- `call.py` demonstrates a request to JSONPlaceholder.
- `bird_v_chicken.py` is an earlier bird-versus-chicken experiment.

The image apps require PyTorch, torchvision, and Pillow. The API examples require Requests.
